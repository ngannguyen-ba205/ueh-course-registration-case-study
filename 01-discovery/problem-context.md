# Problem Context

## Context

Course registration at UEH requires students to make decisions based on class availability during the registration period.

When a class reaches capacity or availability changes, students need to react quickly to secure a suitable class.

## Key Problems

The existing registration experience creates three key challenges:

### 1. Uncertainty

Students are not always sure whether they will successfully enroll when class availability changes.

### 2. Repeated Monitoring

Students repeatedly check the Portal because there is no official mechanism to wait for a seat to become available.

### 3. Enrollment Risk

Students may risk losing their current enrolled class when attempting to switch to another class.

## Root Cause

The underlying issue is not only system responsiveness.

Students lack timely information and adequate process support to make confident course registration decisions.
