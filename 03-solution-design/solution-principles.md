# Solution Principles

The proposed solution was designed based on three key principles.

## 1. Prioritize Reliable Information

Students should have timely and clear information about class availability so they can make informed registration decisions.

The solution therefore prioritizes visibility of current class status rather than relying on students to repeatedly check the Portal.

## 2. Replace Repetitive Monitoring with a Single Action

Students should not need to continuously monitor class availability.

The waitlist allows students to express their intention once and rely on the system to process the enrollment when a seat becomes available.

## 3. Protect Existing Enrollment

Students should not have to give up an existing class before knowing whether the new class can be successfully registered.

The Safe Swap mechanism therefore retains the current enrollment until the new enrollment is successfully confirmed.

## Design Rationale

These principles ensure that the solution addresses the underlying process issues identified during the analysis:

- **Uncertainty** → Improve information reliability.
- **Repeated Monitoring** → Reduce manual monitoring.
- **Enrollment Risk** → Protect existing enrollment.
