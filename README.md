## Problem

The current course registration experience creates three key challenges:

- **Uncertainty** — Students are not sure of successful enrollment when class availability changes.
- **Repeated Monitoring** — Students repeatedly check the Portal because there is no official wait mechanism.
- **Enrollment Risk** — Students can risk losing their current class when trying to switch to another.

The underlying issue is:

> Students lack timely information and adequate process support to make confident course registration decisions.

## Proposed Solution

The proposed solution consists of three key components:

1. **Real-time Class Status**
   - Provides timely information about current class availability.

2. **Waitlist + Auto-Enrollment**
   - Allows students to join a waiting list and be automatically processed when a seat becomes available.

3. **Safe Swap**
   - Protects the student's current enrollment until the new class is successfully confirmed.
